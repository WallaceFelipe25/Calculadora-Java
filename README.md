# Projeto Java - Calculadora

Este projeto visa demonstrar minha evolução no desenvolvimento de sistemas em Java.
Sendo o primeiro repositório público com interface visual, pretendo
utilizá-lo para demonstrar meus conhecimentos na linguagem Java e minha evolução.

Nesta aplicação básica, foi utilizada a biblioteca "exp4j" para calcular as expressões
matemáticas de forma simples e ágil.
_____________________________________

## Como utilizá-lo

A biblioteca exp4j requer a versão 6 do Java.
Porém a aplicação foi compilada utilizando a versão 17. Recomendada esta versão para
execução da aplicação sem erros.

Para iniciar a calculadora, basta executar o aplicativo "Calculadora.exe".
